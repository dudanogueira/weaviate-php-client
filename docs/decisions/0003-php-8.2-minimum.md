# ADR 0003: PHP 8.2 minimum

- **Status:** Accepted
- **Date:** 2026-09-25

## Context

PHP 8.1 reached end of life in December 2025. PHP 8.2 gets security fixes until December 2026. 8.3, 8.4 and 8.5 are actively supported. The community client needs 8.3.

## Decision

Support PHP **8.2 and later**. CI tests 8.2 through 8.5 ([05](../05-testing-and-ci.md)).

## Rationale

8.2 gives us `readonly` classes for results and config objects, DNF types, `true`/`false`/`null` as standalone types, and enums (from 8.1). These cover everything the API design in [03](../03-api-design.md) needs. Starting at 8.2 instead of 8.3 reaches more users on LTS distros, such as Ubuntu 24.04 and Debian 12 with sury packages.

## Consequences

- We can't use typed class constants (8.3), property hooks or asymmetric visibility (8.4).
- **Review:** in 2027, after PHP 8.2 reaches end of life, we'll consider raising the minimum to 8.3 in a minor release. Composer handles that safely.
